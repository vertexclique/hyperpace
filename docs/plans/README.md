# plans

One implementation plan per feature, built from a research judgement. A plan is
a contract a fresh agent reads verbatim: current-truth, forward-only, complete.
Structure: TL;DR, problem, the chosen approach, a per-feature honesty table
(math-correct / honest / scales), phases with gates, scale and streaming,
verification, and a status table with deferred items named.

Run it with: vertexia plan <slug>. No product code until the plan is approved.
See the vertexia-plan skill and templates/plan.md.
