# SUMMARY: Compx ComUsbUpgradeFile DFU protocol (the flashing spec)

- Claim: The HYPACE silicon is flashed by the Compx report-8, 64-byte USB HID DFU protocol with a fixed package format (720B header, payload at offset 8192). Full framing/chunk/checksum/verify/version logic is recoverable from readable vendor code.
- Method: Cross-read three independent implementations of the SAME protocol: deminified WebHID JS (Lofree /home/ and Pulsar), decompiled .NET IL (Pulsar Xlite v3 desktop tool), and an independent TS parser (OpenMouse). Confirmed against a real USB byte log inside the Pulsar 1K dongle tool. Parsed all 45 archived images with a Python header parser.
- Result: header = headCRC(0x55555555 - sum(bytes[8:headLength])), headLength=720, fwLength, nextFileAddress (multi-image chain), version(v maj.min), DeviceType(210 mouse/211 dongle), Cid, Mid, then 11x64B ASCII fields (fileId, icName, boot/normal endpoints, resetToUpdateModeCmd, prepareDownLoadCmd, dataDownLoadCmd, senser/product). Wire: cmd 0x0D enters bootloader (device re-enumerates on boot PID), prepareDownLoad(0xB0), 32-byte dataDownLoad(0xB1) chunks addr big-endian, device replies 0x5B B5, Success=0x88. Order: dongle then mouse. Version check refuses downgrade (web) but .NET AlwaysUpgrade=1 re-flashes any version; no signature, no rollback counter. Payload appears encrypted (high entropy, no valid vector table) and is sent verbatim.
- Evidence tier: 1 (three vendor code implementations + real USB log).
- Performance: 32 B/HID report boot channel; images 17KB-309KB; flash completes in seconds per the logs.
- Correctness: Header CRC verified on all images. Payload CRC-32 (init 0xFFFFFFFF, no final xor) verified for CX dongle payloads but NOT for NRF/CH32 mouse payloads (region/variant differs; corroborated by OpenMouse issue #97). HYPACE-specific boot PID and payload-encryption details are unproven without a real HYPACE image.
- Relevance: This is the exact state machine Hyperpace must implement, and it can be verified code-to-code (no hardware) against the three saved implementations.
