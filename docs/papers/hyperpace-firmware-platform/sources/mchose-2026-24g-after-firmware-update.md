## Snippet text

> The problem of 2.4G mode not working after a firmware update is usually caused by an incorrect firmware update process or incomplete firmware update between the mouse and receiver.

> You must make sure both the mouse and receiver firmware are updated correctly. If only the mouse or only the receiver is updated, 2.4G mode may fail.

> For some models, you must connect the mouse and receiver at the same time using two data cables during the firmware update.

> After updating firmware, manually re-pair the mouse and receiver.
